# Веб‑ассистент пропусков (Gemini)

Веб‑ассистент в стиле Siri/Алисы/ChatGPT для учета пропущенных учебных дней студентов.
Работает локально в браузере, хранит данные в SQLite, общается с Gemini через API.

## Запуск
1. Установите Python 3.10+.
2. Задайте ключ Gemini:

```powershell
$env:GEMINI_API_KEY="ваш_ключ"
```

3. Запустите сервер:

```powershell
python assistant.py
```

4. Откройте в браузере.

## Возможности
- Текстовый и голосовой ввод (без озвучки ответов)
- Команды: узнать пропуски, зафиксировать причину, сделать отчет
- Сводка и последние пропуски на панели справа
- Данные сохраняются локально в `assistant.db`

## Примеры команд
- «Покажи пропуски студента Иванов Иван»
- «Зафиксируй пропуск: Петров Петр, 03.02.2026, 2 занятия, причина — болезнь»
- «Сделай отчет по группе ИС-21 за январь 2026»

## Примечания
- Для голосового ввода используйте Chrome/Edge и разрешите доступ к микрофону.
- Если ключ не задан, ассистент покажет статус ошибки вверху.
- Никогда не вставляйте ключи прямо в файлы проекта — используйте переменные окружения.
